# 🎯 My Claude Usage Strategy

A visual guide to choosing the right Claude model and effort level for learning, research, and project planning.

## 📌 Overview

This infographic helps students understand:

* Which Claude model to use (Haiku, Sonnet, or Opus)
* When to use different effort levels
* How to optimize AI usage on the Free plan
* Best workflows for studying, research, and project development

## 🚀 Key Recommendations

### Recommended Primary Model

**Claude Sonnet**

Why?

* Excellent for learning and studying
* Strong reasoning and research capabilities
* Great balance of speed and quality
* Ideal for students and academic projects

### Recommended Effort Level

**Standard**

Best for:

* Daily study sessions
* Assignment help
* Concept learning
* Note creation

## 🧠 Model Selection Guide

| Model  | Best For                                               |
| ------ | ------------------------------------------------------ |
| Haiku  | Quick answers, definitions, summaries                  |
| Sonnet | Learning, projects, assignments, research              |
| Opus   | Advanced research, technical reports, complex projects |

## 📚 Student Workflow

1. Use **Haiku** for quick doubts and definitions.
2. Use **Sonnet + Standard** for everyday learning.
3. Use **Sonnet + High** for exam preparation and project planning.
4. Use **Opus + Max** only for complex research and major projects.

## ⚠️ Common Mistakes to Avoid

* Using high effort for every prompt
* Asking vague questions
* Starting projects without clear objectives
* Using advanced models for simple tasks
