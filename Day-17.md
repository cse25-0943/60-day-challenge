# 🚗 Fuel Cost & Carbon Intelligence Dashboard

An interactive, data-driven dashboard that analyzes fuel economics, maintenance costs, carbon emissions, and vehicle aging trends across multiple fuel types including **Petrol, Diesel, CNG, E85 (Flex-Fuel), and Electric Vehicles (EVs)**.

Built using **pure HTML, CSS, JavaScript, and SVG** with a modern glassmorphism-inspired UI, the dashboard transforms raw CSV vehicle datasets into actionable insights for drivers, fleet managers, and sustainability enthusiasts.

## ✨ Features

* 📊 Average Cost per Kilometer analysis by fuel type
* 🌱 CO₂ Emissions per Kilometer comparison
* 🔧 Maintenance Cost per Kilometer tracking
* ⛽ Refuel / Recharge time evaluation
* 🚘 Vehicle Age Bucket Analysis (New, Mid-life, Aged, Old)
* 📈 Cost vs Vehicle Age trend visualization
* 🧮 E85 Flex-Fuel Economics ("E85 Paradox")

  * Pump Price Savings
  * Running Cost Penalty
  * Break-Even Fuel Price
* 🎯 Composite E85 Score (0–10)
* 💡 Intelligent fuel recommendations with pros, cons, and best-use scenarios
* 📱 Fully responsive design (375px–1440px)
* 🎨 Dark navy glassmorphism interface
* 📉 Pure SVG visualizations (No chart libraries, No CDN)

## 🛠️ Tech Stack

* HTML5
* CSS3
* Vanilla JavaScript
* SVG Charts
* CSV Data Processing

## 📌 Dashboard Insights

The dashboard helps answer critical questions such as:

* Which fuel type offers the lowest running cost?
* How do emissions compare across fuels?
* Does E85 actually save money?
* How does vehicle age impact operating costs?
* Which fuel is best suited for city, highway, or fleet usage?

## 🎯 Use Cases

* Fleet management optimization

* Fuel comparison studies
* Automotive data analytics projects
