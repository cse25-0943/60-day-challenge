# 🔮 Vedic Astrology Life Report UI

A modern, responsive astrology report interface designed to present detailed Vedic birth chart analysis in a clean and visually appealing dashboard format.

## ✨ Features

- 📋 Birth Chart Summary
- 🌙 Planetary Placements
- ⭐ Lagna, Moon Sign & Nakshatra
- 📈 Career & Wealth Analysis
- ❤️ Relationship & Marriage Insights
- 🪐 Current Dasha Analysis
- 📅 5-Year Forecast
- 🙏 Traditional Remedies
- 📱 Responsive Dashboard Design
- 🎨 Clean UI inspired by modern astrology websites

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
